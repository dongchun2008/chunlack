# VPS 硬件需求与部署进度

更新日期：2026-09-08。

## 推荐配置

VPS 负责运行 LACK 和协作服务，模型通过云 API 或独立 GPU 服务器调用。
在此前提下，VPS 不需要 GPU，也不需要安装 CUDA。

| 项目 | 起步试用 | 推荐配置 | 后续扩展 |
|---|---|---|---|
| CPU | 2 vCPU | 4 vCPU | 8 vCPU |
| 内存 | 4 GB | 8 GB | 16 GB |
| SSD | 40 GB | 80 GB | 160 GB 以上 |
| 用途 | 少量 Agent、基本聊天 | 多 Agent 协作和研究任务 | 增加 RAG、浏览器和 MCP 服务 |

以上为容量估算，尚未通过目标 VPS 压力测试确认并发能力。
若服务器已有其他项目，应在现有占用之外预留资源。
已有 2 核 4 GB 的 VPS 可以先部署试运行，再根据实际负载调整。

## 系统与网络

- 推荐 Ubuntu Server 24.04 LTS，x86_64/amd64，KVM 虚拟化。
- 需要 SSH、sudo 权限及安装 Docker Engine、Compose 的条件。
- 网络应稳定访问所选模型 API、镜像仓库和软件源。
- 连接独立 GPU 服务器时，两端需要私网或 Tailscale 连通。
- 文本协作带宽可从 10 Mbps 起步；附件、抓取和镜像下载需要更多余量。
- 部署时建议至少保留约 20 GB 空闲磁盘，用于构建、升级及备份。
- 初期通过 SSH 隧道访问；应用端口仅发布到 VPS 的 127.0.0.1。

Docker 系统支持范围见 [官方安装说明](https://docs.docker.com/engine/install/ubuntu/)。
