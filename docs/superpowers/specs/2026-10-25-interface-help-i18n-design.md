# ChunLACK 界面与帮助多语言设计

日期：2026-10-25。源基线：`89337030e9a981bf8c525ea36fc4beb3a85278a0`。

## 目标与授权边界

用户要求界面与帮助支持多语言，至少包含英文和中文，并持续推进完整交付。采用已说明的轻量语言包作为工程默认，不引入前端框架、翻译服务或模型调用。不声称用户逐项审核了下述内部 API。当前仅本地开发与模拟验证，不部署、不调整 Agent，不修改凭据、授权、DNS、端口或 Relay。既有 Linux 4/4 单元已经耗尽，不能把持续执行目标当作重置额度或新维护窗口。

## 方案取舍

- 选择：普通 JavaScript 语言控制器与静态语言包，适配现有内嵌 HTML、工作区组件与 materialize 流程，新增语言以扩展语言包为主。
- 不选择：为了国际化迁移整个前端框架。资源、依赖和回归范围与当前轻量私有部署目标不符。
- 不选择：运行时调用模型翻译，或遍历页面自动替换所有匹配文字。前者引入费用、延迟和数据外发，后者可能改写用户姓名、消息、来源及逐字引用。

## 语言与身份

首期提供 `zh-CN` 与 `en`。未选择时按浏览器首个受支持语言，最后回退简体中文。语言偏好存入当前浏览器的独立键，区分匿名状态和真人账号；同一账号切换工作区不改变偏好。账号切换、退出与跨标签页更新不应把另一个账号的偏好当成本账号设置。语言 ID 不参与认证、工作区授权或 Agent 路由。

存储不可用时保留页内偏好并降级，不影响登录。不得把会话、令牌、提示词或凭据写入语言存储。当前不增加数据库字段，也不承诺跨设备同步语言。

## 受控文案绑定

`identity/i18n.js` 提供独立控制器、命名参数、静态语言包选择、订阅、显示标签和可关闭的视图绑定。只有控制器创建的标签对象会随语言变化；普通字符串和 API 数据始终按原文显示。标签身份保存在 WeakMap 中，不根据来自 JSON 的 `id` 字段或字符串内容认定。

绑定仅允许文字、标题、占位提示及可访问性描述，拒绝 `innerHTML`、URL、事件、样式和输入值绑定。参数作为文本写入，不解析 HTML。语言切换不重新加载页面、不重新创建业务组件，不覆盖草稿、表单值、研究原文或事件处理器。清空面板时释放对应绑定，关闭页面或组件时退订，迟到回调不再改写已关闭视图。

现有界面文案以明确的消息 ID 和参数进入语言包；迁移时允许以原始界面文案作为消息 ID，缺失项依次回退中文包和原文。完整集成验收还须独立检查双语覆盖，不能用回退成功代替翻译齐全。翻译必须保留参数名称；错误诊断不带存储异常原文、参数或用户内容。

## 界面与帮助覆盖

完整范围包括登录、工作区与账号栏、成员、节点、任务、Agent 授权、创建 Agent、聊天界面控件、状态和错误提示、研究报告的界面标签，以及中英文使用手册。用户名、Agent 名称、频道名、任务目标、模型输出、研究陈述、引文、来源 URL、原始摘录与历史消息不自动翻译。

目前 `/help` 会由服务端生成并广播英文消息。新的界面帮助应优先在用户自己的帮助面板展示，避免改变共享频道记录或向模型额外发请求；命令拼写、后端权限和旧客户端兼容保持不变。帮助应区分当前运行模式与未授权、禁用或未验收能力，不能因翻译而开放 `/bash`、`/pull` 等既有限制。

手册保留完整中英两版，必须一致地区分历史验收、当前本地开发与尚未发布功能。保存的玄玑单任务验收不等于事件唤起或长期稳定性；老镇为历史名称，苏婳的新账号接入仍须独立验证。

## 集成与发布

浏览器资源在现有同源资源链路加载，不依赖 CDN。CommonJS 导出只供测试和已有构建工具使用。资源必须由 materialize 一并带入运行时；帮助资源只通过固定语言白名单提供，安全文本显示，不将任意路径或任意 HTML 作为帮助输入。

本功能将改变四文件研究补丁之外的运行时文件，不能夹带到已准备的四文件发布清单。生产发布需新的精确清单、兼容及回滚证明、新资源额度和独立维护授权。整个多语言功能尚未完成前，基础模块通过不等于可交付界面。

## 验收要求

1. 两种语言的静态、动态及可访问性文案覆盖；语言包参数与消息 ID 对齐。
2. 匿名、两个真人账号及多个工作区的语言隔离，存储失败和跨标签页行为。
3. 切换时不丢草稿、不重复提交、不增加模型请求、不重复注册业务事件。
4. API 用户文字即使与标签相同仍保持原文；引文、URL、来源及证据持久化不变。
5. 登录、成员、节点、任务、研究报告和权限拒绝路径的双语真实界面集成回归。
6. 中英完整手册、私有帮助、不广播 `/help` 的界面路径，以及受限命令原有拒绝。
7. 桌面与移动端实际布局、完整本地回归和烟雾测试；原生与生产验证单独列明。
