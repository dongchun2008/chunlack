# 候选准备外层有界执行

延续独占预留方案，先完成本地实现和模拟验证，不连接 VPS、不执行单元、不发布。既有源码和失败现场保持原样；不改 Agent、凭据、授权、DNS、端口或 Relay。

1. 用失败优先测试实现完整编排：四服务／配置基线、精确新标签单元不存在、固定包独占接收、预留、启动 claim、单次启动、固定 InvocationID 跟踪、结果与实际退出核对、停止／cgroup 清空及最终保护核对。任何失败都保留原始与清理错误，不将未知退出码填 0。
2. 实现 Linux 主机适配器：只接受上一阶段固定包；逐成员校验及独占落盘，不使用 extractall，不接受链接／路径穿越。启动仅使用已核验 typed request。所有命令有输出、等待、杀回收上限；不执行任意调用者命令。
3. 本地 SSH 接线复用已有主机指纹验证、认证后读取凭据、通道输出上限和全部句柄清理机制。外部一次性本地记录必须早于连接。远端总封套 120 秒、本地 150 秒为待原生审批的计划；准备业务单元仍为 5+80+5 秒、192MiB／20% CPU／32 Tasks／零交换／隔离网络。清理时间不得被等待和取证耗尽。
4. 完成模拟回归和一次整体只读复核；仅同步方案和脱敏记录。真实内核、D-Bus／systemd、资源及服务连续性不由本地通过推定。

本阶段不安装启动器、不读真实数据库、不生成兼容证明。后续原生准备前须把固定包、上传路径、单元额度、数据只读范围和保护基线列为一个关键执行节点；不复用此前额度。

本地验收：232 项关联回归通过，零失败／错误／跳过，实际退出码 0；包含原163项、53项新外层测试、6项派生请求、9项派生worker绑定和1项派生真实本地文件组合测试。独立只读复核报告的清理中断、过早成功记录、最终stdout迟到三处P2均已失败复现并修正，最终无已确认未关闭P1/P2。POSIX权限、systemd和挂载仍未原生执行。

挂载修正：新派生归档仅改变 request.py 与两层源码摘要，加入 `BindReadOnlyPaths a(ssbt) [[root,root,false,0]]`，保留 PrivateTmp 及仅两新候选根目录可写的限制。旧93文件包与源文件未改。依据 [systemd v255 D-Bus实现](https://github.com/systemd/systemd/blob/v255/src/core/dbus-execute.c) 的签名及允许flags，配合 [PrivateTmp 官方说明](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec)；实际挂载可见性仍待验证。

回执边界：outcome.json 和 terminal.json 始终是 provisional、accepted=false，候选成功另记，不能单凭文件判断完成；须核对最终stdout、实际进程退出及实际耗时。已实现子进程149秒上限、远端120秒timeout封套及父层150秒输出后检测。父层持久化和最后输出不能由合作式检查抢占阻塞，不能称为已证明的严格总耗时上界。

已生成未启用外层包，approvedExecution=false，保留固定ED25519校验及验证主机后读取凭据的既有传输。父层／SSH一次性记录早于启动与连接；失败不重试。不提供删除失败候选、旧写锁或恢复授权的入口。
