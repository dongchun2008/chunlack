# 中英文界面与帮助实施计划

源基线：`89337030e9a981bf8c525ea36fc4beb3a85278a0`。设计见同目录上级 `specs/2026-10-25-interface-help-i18n-design.md`。

## 全局约束

仅本地开发与模拟测试，不发布、不调整 Agent、不调用真实模型，不改凭据、授权、端口、DNS 或 Relay。不重置或增加此前 Linux 额度。不得把基础模块或单元测试当作完整界面、原生 Agent 或生产交付。

## 任务顺序

1. 新增 `identity/i18n.js` 与 `tests/i18n.test.cjs`：独立语言控制器、真人浏览器偏好、显式文案标签、命名参数、安全属性绑定、取消和释放。先保留缺少接口的失败证据，再验证实现。
2. 以独立文档任务校对 `docs/USER_GUIDE.zh-CN.md`，新增完整 `docs/USER_GUIDE.en.md`；依据仓库的具名验收记录更新过时状态，不把文件记录说成当前线上实测。
3. 新增 `identity/messages.js`，完成现有中英界面消息包。按控制器标签接入 `identity/workspace-shell.js`，新增 `tests/i18n-ui.test.cjs` 并补齐现有工作区组件回归；保持业务数据、权限和事件生命周期不变。
4. 接入 `identity/login.html` 与 `lack.py` 的主界面、资源路由和内嵌脚本，分别提供账号栏及旧单用户模式的语言入口。补齐创建 Agent、静态与动态界面、可访问性标签以及原有双语兼容回归。
5. 新增 `identity/help.js` 与 `tests/i18n-help.test.cjs`，提供用户私有帮助和语言匹配的完整手册；按固定语言映射打包和读取资源，补齐 `scripts/materialize.py` 与 `tests/materialize-workspace.test.cjs`。保留命令权限、协议标识和旧客户端兼容，不改写历史消息。
6. 验证未翻译项、参数一致性、真实 DOM 的语言切换、草稿和表单保存、两账号/多工作区隔离、XSS 文本安全、关闭及迟到回调。执行完整本地回归、烟雾和桌面/移动端界面验证后，独立复核并同步脱敏记录。
7. 另行准备包含本功能的新发布范围。只有获得新的原生资源额度并完成相应兼容、成功/失败恢复演练及新维护授权，才允许生产切换。

## 当前状态说明

首次阶段只实现并验证语言基础模块和校对手册。第 3 至 7 项尚未完成，语言入口尚未在生产启用。后续同步记录须逐项更新真实结果，不沿用过期发布证明，不将四文件研究补丁门禁用于放行新语言资源。
