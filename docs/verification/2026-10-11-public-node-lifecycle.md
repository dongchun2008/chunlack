# 网页任务创建与实际节点生命周期验证

## 本轮实现

基线为 `bf748c3de50fb24929263b3e2bb2032aad5361e6`。补齐实际打包网页缺失的受限外部任务入口：`POST /api/tasks`，由真人会话、当前工作区、成员权限及 CSRF/Origin 控制，只接受 targetNodeId。复用现有队列、全局执行槽、租约和取消逻辑；服务端生成随机 challenge、固定 example.com 地址及五分钟期限，不允许调用者扩大 URL/范围/任务类型/期限。

节点面板增加“公开浏览试点”和页内确认，保持原牛油果样式、textContent 渲染与面板生命周期控制。成员可提交，只读成员不能提交；暂停、撤销、混合能力、非 public 节点均不显示该按钮。面板关闭或工作区切换使待确认操作失效。

## 生命周期端到端覆盖

`tests/packaged-node-lifecycle.test.cjs` 运行真正生成的应用及真正 Caddy，使用自行生成且验证信任的测试证书，以网络请求而非直接 store 操作完成以下行为：

- 三位合成人类账号、两个工作区、三个 WSS 连接，五个登记并配对的合成浏览器节点；拒绝第六个节点、只读成员提交、缺 CSRF 和跨工作区节点选择。
- 真人创建任务，节点从限定 taskId 领取；A 区租约占用时 B 区不能执行，仍共用全局单槽。
- started/heartbeat、真人取消、取消期间拒绝迟到结果；未取得匹配 cancelled 事件之前保持执行槽占用，确认后 B 区才获得租约。
- 暂停节点不能领取，恢复后可以领取。上传有效合成 PNG；重复上传返回同一 artifactId，完全相同结果事件重投返回同一确认，不重复完成。
- 运行中撤销使旧 token 立即失效，但未确认远端停止仍保留租约。实际关闭/重开应用后先恢复未过期租约，再决定能否接纳 B 区任务；被撤销凭据仍无效。
- 重开后 A/B 任务列表隔离、结果状态持久化、校验码不出现在真人列表，原会话可以重新建立 WSS 连接。

该完整多阶段流程只计一个 test，不把每个 HTTP 请求或断言虚报为一次 Agent 协作。期间所有账号、节点、PNG、活动记录和模型服务都是合成夹具；没有访问 example.com 或外部平台，也没有 Muse/dots 自身浏览器活动。截图校验成功只证明本机证据存储链，不能证明截图内容来自真实网页。

## 发现但未修正的边界

网页按钮限制为专用 public 浏览器身份，创建 API 目前只复用 store 的包含式能力/范围授权，二者尚未完全一致。混合能力或多范围节点可能经 API 获得浏览试点，但专用截图 facade 又拒绝这类身份；有形成不可完成任务的风险。这是本轮补入口时发现的遗漏，不宣称本次测试已覆盖或修复。已告知用户并提出最小修正及重新完整复验，尚未实施该修正。

任务进度面板也不能代替逐任务证据查看、人工验收和外部节点实际活动核对。两项均保留在交付缺口中。
