## 安全边界

- 初始只读 SSH 信任来自用户提供并已固定的 ED25519 指纹；自动密钥认证失败后用此前获授权的密码登录，不更新凭据，不打印密码。
- 新鲜基线：原 LACK PID 234963、tailscaled PID 859，均 active、NRestarts 0，健康检查 200，Relay UDP 监听六行，主机无 TCP 443 监听。MemAvailable 1112896 KiB，实际 MemTotal 1651808 KiB；不按标称内存推测容量。
- 独立 systemd 测试单元的私有网络命名空间和 RootDirectory，源码及依赖只读。仅本次 evidence、临时目录和打包 TLS 夹具目录可写；没有生产数据或凭据挂载。
- 主试验 CPUQuota 为单核 50%、MemoryMax 256 MiB、TasksMax 64、RuntimeMaxSec 900；独立只读基线监测为 5%、32 MiB、16 个任务。监测若发现既有基线变化，只停止本次试验单元，不修改原服务。
- 测试使用随机回环高端口；不切换生产、不占主机 443、不改 DNS、防火墙、Tailscale/Relay 或 Open WebUI，也不读真实模型密钥。

持续阶段有三个虚构真人会话、两个工作区，每区五个不同模型 Agent，共十个逻辑 Agent；五个已配对的合成执行节点保持空闲。两个工作区各 40 轮，400 次主回答请求、800 次总生成请求，最大生成 HTTP 在途数 1。每轮要求五个主回答及新任务记录完成，没有把单个请求、辅助反思、节点注册或部分回答算成完整一轮。

主试验整个 cgroup 的内存峰值 137404416 字节（约 131.04 MiB），CPUUsageNSec 134756685000（约 134.76 秒）。持续脚本报告的主进程观测 RSS 120.0625 MiB、CPU 13742.883 ms、轮耗时 P95 2291 ms；后者不包含 Caddy 子进程，也不包括原有轮间冷却，应与整体 cgroup 指标区分。

三十次有界共存采样保留原服务 PID、重启次数、健康检查及 UDP 监听，结束标记为 `NATIVE_COHOST_BASELINE_MATCH`。中途 SSH 观察连接丢失，但没有重复启动或重跑任务；重新认证后读取原单元及原日志确认实际成功。
