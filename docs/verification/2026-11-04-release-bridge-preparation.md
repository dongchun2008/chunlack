## 最小接线设计

1. 新建私有演练副本，保留所有冻结与已部署文件。
2. 普通节点保持 UID996/GID987、零能力及现有严格规则；受限 root 控制器单独验证身份、既有能力边界、NNP、阶段、单元与完整 cgroup，不扩大白名单。
3. 私有 `/run` 策略只用于经过验证的隔离演练，不直接套用到正式发布启动器。主机服务管理接口必须保持不可达。
4. 明确 `/run/lock` 与既有写锁的关系；私有锁不能冒充主机全局发布锁。缺失旧 socket 屏蔽参照也不能单独当作隔离成功。
5. 控制器日志只允许精确绑定的自有路径及描述符，不放宽普通节点规则。
6. 更新新副本的完整摘要链和嵌入源码绑定，增加身份错配、挂载漂移、锁、日志、取消清理及回滚兼容回归。

以上为待实施方案，本阶段没有执行这些开发或测试。
