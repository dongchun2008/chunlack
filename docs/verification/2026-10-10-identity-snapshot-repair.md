# 身份接口与源数据库读取修正验收记录

日期：2026-10-10（Asia/Shanghai）。范围：用户明确批准的身份接口、快照读取链路及完整本地复测；不包含生产切换。

## 已修正

- 网关离线转换按现有接口使用 `requireMembership(ownerId, workspaceId)`，保留当前所有者检查和提交前再次检查，不降低授权要求。
- 计划、身份源核对、快照描述和原生 SQLite 备份统一使用私有副本读取器，不再直接用 SQLite 打开操作者的原库。
- 主库与已有 WAL 均经过有上限的流式复制、哈希及文件身份比对；源文件变化时失败，不以主库单独复制代替已提交的 WAL 数据。
- 只允许 SQLite 在本次创建的私有目录内恢复 WAL、切换副本日志模式；调用方取得只读副本，关闭后清理本次拥有的读取目录。
- 非空回滚日志、链接、损坏数据库和超限文件均拒绝处理。Windows ACL 未验证的限制仍保留，不能宣称已有 Linux 权限证明。

备份仍使用 SQLite 原生 `backup()`，但其输入现在是经稳定性校验、包含 WAL 的私有副本。它不是持续写入期间保证在线迁移成功的方案；检测到源变化就停止。单文件读取上限为 64 MiB，内存使用流式缓冲；仍需在正式迁移及 VPS 隔离验证中检查磁盘空间和资源限制。
