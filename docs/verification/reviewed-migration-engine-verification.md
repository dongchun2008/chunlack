# 正式迁移执行与离线校验：本地验收

## 实现范围

新离线执行器接受经审阅计划、已验证快照、当前所有者身份源及显式模型授权。它转换旧核心协作及研究表、停用旧节点凭据、保留有效租约，并将受支持快照完整保存在独立候选的隔离目录。原库和原配置不写入，不启动服务。

执行器验证源文件、WAL、身份绑定、模型授权、原图证据、数据库完整性／外键、计数和完整文件清单。最后才发布候选清单和就绪配置；中断或失败维持不可启动状态。同一计划再次执行只校验成功候选，未知目标绝不覆盖。

已提供 `--prepare-snapshot`、`--apply --reviewed --plan-file ...` 和 `--verify --plan-file ...` 命令行入口。无明确审阅或输入不完整时拒绝执行。详见 `../reviewed-workspace-migration.md`。
