# ChunLACK 预接入发布与后续接入说明

2026-10-17 已完成本次批准的公网预接入发布。应用和 HTTPS 入口已更新，维护中断计时为 32.003 秒。当前是 OAuth 发现模式，外部 Agent 任务执行尚未开放，也尚未完成 Muse、dots 端到端交付验收。

## 访问与登录

- 真人入口：[ChunLACK](https://lack.chunclaw.top/)。本机内置浏览器已实际显示登录页和 Pocket ID 登录入口。
- 点击“使用统一身份登录（Pocket ID）”，使用原有账号，再选择已经获得授权的工作区。本次没有创建账号或扩大工作区权限。
- Agent 接入地址为 `https://agents.chunclaw.top/mcp`，供连接器配置使用。
- 发现文档地址为 `https://agents.chunclaw.top/.well-known/oauth-protected-resource/mcp`。

发现路由和业务授权是两个步骤。当前 `enabled=true`、`discoveryOnly=true`、Agent OAuth 客户端名单为空，事件功能关闭。发现文档可由服务端提供，但 MCP 业务请求返回 401，公网 `/v1` 和 `/v1/*` 返回 404。不要把发现成功或 HTTP 收件确认当成任务执行成功。

## 本次验证结果

- 已部署的 56 个运行文件与已验证候选包逐项哈希一致。运行包 SHA-256 为 `d793affff1bda571cc6a7b4ba1970d9e0379f9e7549d6136fd2a699f23018389`。
- Linux 部署控制器回归 15/15 通过，包含中断恢复、全局时间预算、部分复制失败、监听归属、权限、配置保留和历史数据库归档边界。
- 独立测试服务实际完成正常切换和故障回滚，分别约 23.3 秒和 27.6 秒。测试进程和专属 cgroup 均已退出。
- 新旧实际运行时在独立网络、只读源目录和数据副本中启动、关闭成功，三个运行库的结构保持一致。这是兼容性检查，不是回滚备份；测试中的 OIDC 元数据读取使用经过 TLS 验证的公开发现文档与 JWKS 缓存，不代表真人登录验收。
- 正式切换前，停止写入后保存并校验了包含 552 个文件、三个运行库的一致性备份。没有用运行中的副本替代该备份。
- 正式 HTTPS 检查验证了健康接口、两条发现路径、MCP 拒绝和节点 REST 拒绝；检查保留了域名、SNI 和证书校验。
- 旧 LACK 与 Tailscale Relay 的 PID、重启次数未变化，Relay UDP 40000 仍监听。未测量本轮实际 Relay 转发吞吐。
- 发布后的一次只读采样中，公网应用约占 54.0 MiB，HTTPS 入口约占 13.1 MiB。该采样不代表压力上限；没有增加常驻生产服务。

原应用代码的 856 项本地回归和 8 项受限 Linux 专项测试仍保留在此前的验证记录中。本轮没有修改模型路由或重新执行真实模型、多人长期协作、五 Agent 持续负载验收。

## 客户端访问仍待核验的部分

本机内置浏览器能够打开真人登录页，但访问 Agent 发现文档时返回 `net::ERR_BLOCKED_BY_CLIENT`。本机 Python 的两个公网 HTTPS 探测也未取得通过结果。服务端的带 SNI HTTPS 检查已通过；这些客户端结果仍分别保留，不能据此声称第三方 Agent 的外部网络路径已经验收。

本轮没有为绕过该客户端拦截而关闭证书校验、切换访问方式或修改本机安全设置。拦截的具体来源尚未确认。

## Muse（老镇）与 dots（玄玑）下一步

目前只能配置接入目标，尚不能领取任务。公网方案使用上述 HTTPS 地址，不要求为这条接入再建立 VPS 隧道。

1. 账号可用后，核对各自实际提供的第三方连接入口、客户端身份和完整回调地址。Muse 账号当前无法登录，相关能力保留为待验证。
2. 为外部 Agent 登记独立客户端和最小工作区授权。不能复用 ChunLACK 真人登录的 Client Secret，也不能把 Muse Gadgets SDK token 当作 OAuth 客户端密钥。
3. 在客户端身份和授权明确后，另行开启经过批准的业务范围，先验收一个有唯一任务编号和随机校验码的公开网页任务。
4. 验收必须包含外部 Agent 自己的电脑或浏览器活动、截图或文件证据、匹配的任务编号，以及 ChunLACK 的结果持久化确认。自建 worker 的执行、模型文字回答或事件 HTTP 2xx 均不能代替这些证据。

本次没有创建外部 Agent 客户端、授予访问、建立订阅或修改 Pocket ID 配置。因此“发现模式已发布”和“两个外部 Agent 已接通”仍是不同的验收状态。
