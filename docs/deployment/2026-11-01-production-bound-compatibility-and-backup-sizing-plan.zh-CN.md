## 兼容验证的最小实现

1. 在新独占目录使用已有固定版本的候选源码、旧版源码及依赖；不更新产品代码、提供商路由或已部署控制器。
2. 仅在 VPS 内取得真实配置、入口和专用运行环境文件的一致性字节绑定。配置原始字节必须保留；不得向本地、聊天、日志或 GitHub 返回正文。
3. 如需在测试进程中使用现有专用私密运行环境，须另行明确批准。只允许服务器内受限副本或既有受支持的只读传递方式；原文件、值及权限不变。不得涉及 SSH、Relay 或其他服务的凭据。
4. 使用逐库只读备份得到数据库副本，明确不声称跨库应用一致性。保留原始记录和结构；不读取或写入生产任务结果。
5. 兼容单元仅按候选版、旧版顺序启动应用。核验真实内核 UID996/GID987、NNP、零业务能力、固定 cgroup、资源上限、三个私有监听、私有节点读取、转发节点访问拒绝、退出和写锁释放。
6. 私有网关探针不得通过新增真人成员、工作区权限、授权或 epoch 来构造成功。优先复用副本中已有的合法工作区归属，仅在网关副本中构造临时测试节点；授权指纹前后不一致则停止。
7. 在测试专用、摘要固定的启动适配层提供仅供初始化的 OIDC discovery／必要公开密钥 GET 测试响应。地址须从已经验证的原配置派生并精确绑定，最多四次此类 GET；禁止登录、授权码、令牌端点 POST 和任何真实身份授权操作。
8. 保持隔离网络；另行拒绝并计数非本轮回环服务的连接。发现模型请求、shell／Git 调用、任务自动执行或其他未经批准的出站尝试即失败，不重试、不后备，不通过修改 Agent 设置掩盖问题。
9. 测试适配层不得进入产品源码包或生产启动参数。报告须分别记录应用启动兼容、模拟 discovery、真实身份验收未执行、真实模型调用为零，不混称完整登录验收。

## 证明及正式附件的绑定

- 复用现有证明校验器，不放宽安全断言或有效期。
- bindings 必须精确匹配候选／旧版源码、真实配置原始字节、payloadCommit 及依赖。
- i18nBindings 必须匹配实际准备的 configHash、envHash、caddyHash、finalCaddyHash、loopbackCaddyHash、authorityFingerprint 和 controllerFingerprint。
- 真实入口的字节转换、语法和回环投影应分别验证并记录。不得把隔离 Caddy 文件的摘要换写成生产入口摘要，也不得声称应用兼容单元运行过未实际运行的生产 TLS 配置。
- 若在上述不扩大权限的条件下无法形成完整真实绑定，停止并报告；不得签发 passed 证明或伪造启动记录。
- 维护前重新核对证明时效和全部绑定，建议保留至少五分钟余量；过期不改时间戳，需要新的单独有界兼容验证。
- 现有证明的必需启动字段不要求 Caddy 启动，因此应用兼容单元不得以补证明为由重跑整套 TLS／切换／回滚。

## 备份计量

1. 首先从固定摘要的控制器确认实际备份输入及链接处理语义；不能用凭空假定的目录清单代替代码范围。
2. 计量只读取元数据，不读取文件正文，不打开业务 SQLite 连接，不生成真实备份。现有备份只影响可用空间，不清理或覆盖。
3. 拟用保守上界覆盖现网代码、运行数据、入口及运行环境，并计入候选包、数据库 WAL／SHM、目录／归档开销和恢复临时副本；具体输入必须与固定控制器范围核对。
4. 固定根目录，不使用 shell 拼接的 find／du 或任意路径。使用有界、不跟随未核验链接的目录遍历；上限 20,000 项，拒绝不可判定的链接语义、越界、读取错误、计数溢出和遍历期间漂移，不把失败项目计为零。
5. 记录逻辑大小、分配大小、文件类型计数和计量时点，仅返回汇总及私有指纹，不返回敏感路径或内容。若现有链接不能在既定语义内保守计量，则停止，不自动扩大根目录。
6. 拟用空间门槛为 512 MiB 与保守备份／恢复上界加候选包及至少 256 MiB 余量两者中较大值；保留份数、复制上界及实际公式须在本地夹具中明确，不能以空间分区总量或可用空间下限代替实际计量。
7. 此计量不产生应用一致性备份。正式维护仍须在既定 55 秒前向／120 秒总恢复窗口内取得一致性备份、核对空间，并保留不覆盖新写入和不删除遗留写锁的限制。

- 本地实施建议：一个生产绑定兼容准备适配器、一个元数据计量器及相应模拟回归，复用现有证明校验器和应用生命周期；不改产品核心或已部署控制器。
- 新的远端只读采集、生产私密运行环境的服务器内使用、新隔离单元均尚未批准。
- 后续可申请最多一次有界只读计量和一个新的应用兼容单元，不重跑本轮三个成功单元；采集与业务单元的具体脚本、哈希、时间及资源限制需先通过本地回归和独立复核。

- 含私密材料的本轮副本不得成为普通失败日志附件。只有确认自有进程清空后，才可按另行批准的精确路径处理其清理；归属或清空无法证明则保持私有权限并报告，不误删旧失败目录或原凭据。
