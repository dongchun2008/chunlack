# Muse 与 dots 接入准备：公开文档核对

核对日期：2026-10-17。对应仓库检查点：`786766d5aab83a7c079b28727f63881e75de62fd`。

本说明补充[预接入发布说明](PREACCESS_RELEASE_2026-10-17.zh-CN.md)，不是外部 Agent 已接通的验收报告。本轮没有修改产品代码、VPS 配置、凭据、授权或订阅；没有重复发布，也没有重新执行此前通过的测试。

## 当前边界

- 真人入口：`https://lack.chunclaw.top/`。
- 外部 Agent 的 MCP 地址：`https://agents.chunclaw.top/mcp`。
- OAuth 资源标识同上，不使用真人登录客户端替代 Agent 客户端。
- 已发布的是 discovery-only 模式。上一轮发布验收记录显示 MCP 业务拒绝访问，公网 `/v1` 与 `/v1/*` 拒绝访问，事件关闭，外部客户端名单为空。
- 上述线上状态来自已有发布记录，本轮没有取得新的 VPS 健康或配置采样，不把历史状态写成刚刚复验通过。

## dots：回调地址必须取自实际管理页

本轮查阅 [OpenAI 官方认证文档](https://developers.openai.com/plugins/build/auth)。文档支持 CIMD、DCR 或预定义 OAuth 客户端；具体选择仍需与实际账号入口及 Pocket ID 能力匹配，不能仅凭文档自动启用。

1. 在实际连接器管理页取得完整生产回调地址和客户端身份。
2. 若使用 CIMD，记录实际显示的客户端元数据 URL；若使用预定义客户端，记录独立 Client ID。
3. Pocket ID 仅登记与该连接方式匹配的准确回调，不根据旧教程猜测，不添加通配符，不复用 ChunLACK 真人登录客户端。
4. 保留 S256 PKCE、签发者、资源受众、作用域以及 ChunLACK 工作区授权校验。OAuth 登录成功不等于获得工作区任务权限。

官方文档区分固定回调与带 callback ID 的回调；选择取决于签发者识别能力及连接器具体情况。因此，不能现在预填一个假定通用的回调地址。

本轮在受控浏览器中打开 `https://chatgpt.com/plugins`，以及随后恢复该页的两次操作均超时，未取得账号页面内容。此结果不证明账号未登录、不支持接入，或 ChunLACK 服务故障。此前发现地址的 `ERR_BLOCKED_BY_CLIENT` 与本轮页面加载超时也不能认定为同一原因。

需要用户补充的非密钥信息：连接器是否已建立、完整回调地址、Client ID 或客户端元数据 URL。不要发送 Client Secret、令牌、授权码或带授权码的完整登录 URL。

## dots：事件与自身电脑执行分开验收

[OpenAI 官方 MCP Events 文档](https://developers.openai.com/plugins/build/mcp-events)说明 dots 可使用 Events，但受工作区控制；要求 MCP 2.0 协议 `2026-07-28`、持久订阅及出站 HTTPS。

本轮源码检索发现 `integrations/mcp/pilot-server.cjs` 已包含该协议版本，并有 `server/discover`、事件方法及授权边界。这个静态结果只能排除“代码完全未声明该版本”的判断，不证明完整协议兼容、实际订阅或账号权限已经通过。

后续应先完成独立客户端身份和最小工作区授权，再按批准范围启用业务及事件。不得为了让连接器建立即开放匿名任务、伪造工具发现结果或提前接受订阅。

单次试点使用唯一任务编号和随机校验码，让玄玑实际操作自己的云端浏览器访问公开网页，回传网址、标题、执行时间和截图。必须同时核对真实活动记录、任务编号、截图及 ChunLACK 持久化收件结果。事件 HTTP 2xx、服务端代抓网页或自建 worker 都不能代替该验收。

## Muse：自定义连接器可行，但具体接口仍待验证

用户提供的 [Meta 官方连接器说明](https://www.meta.com/help/artificial-intelligence/1687253048996149/)本轮可读取，其中明确说明：未在现有列表中的服务，可以请 Muse 创建 Custom Connector，并按流程取得服务 API 信息；连接器凭据由其安全凭据存储管理。

这为老镇接入 ChunLACK 提供了官方支持的探索路径，但该说明没有给出通用任务唤醒 API、MCP Events 兼容保证、准确 OAuth 回调或当前账号的创建权限。不能据此宣布自动协作已实现。

账号恢复可用后，可以向老镇发送：

> 请只读评估为我的私有 ChunLACK 创建 Custom Connector 的实际要求。目标 MCP 地址是 https://agents.chunclaw.top/mcp，目前只开放 OAuth 发现，任务访问尚未开放。请说明你支持的协议和认证方式、需要登记的准确回调及客户端标识、能否由外部事件触发你使用自身云端电脑并回传结果。不要创建授权、订阅或凭据；无法确认的项目请标注未知，不要把普通 worker 当作你本人执行。

不要把 Muse Gadgets SDK token 当作通用连接器的 OAuth Client Secret，也不要为该公网 HTTPS 路径另装 Tailscale 或修改现有 Relay。

## 下一步与停止条件

1. 先取得两端实际客户端信息；Muse 未能登录时，不猜测或代建其客户端。
2. 将拟新增客户端、工作区、工具范围、有效期及撤销方式列明，再完成涉及新增敏感访问的确认。
3. 按已验证发布路径启用批准的最小范围，执行一个公开网页任务；失败时保留失败环节，不用模拟结果替代。
4. 单次闭环通过后才测试自动事件、撤销、重复投递、重启恢复及多人隔离，最后开展多 Agent 持续验收。

浏览器安全拦截、身份或回调不明确、授权超范围时均停止该接入步骤；不降低 TLS 校验、不开放匿名业务、不扩大公网端口，也不改旧 LACK 或 Tailscale Relay。
